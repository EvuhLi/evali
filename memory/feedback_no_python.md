Use the Edit tool directly for CSS and HTML changes. Do not use Python (or Bash python3 scripts) to manipulate files.

**Why:** User preference — direct edits are cleaner and easier to review.

**How to apply:** Always reach for the Edit tool for any CSS/HTML modification, even bulk find-replace. Use Write only for full rewrites. Never shell out to python3 for file manipulation.
